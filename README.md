# Python Quiz Application 🎯

This is a simple Quiz Application developed using Python, Tkinter, and SQLite.

# 🚀 Features
- Category selection
- Python, SQL, and C programming questions
- Multiple choice options
- Score calculation
- Warning message if no option is selected
- Final score display after quiz completion

# 🛠 Technologies Used
- Python
- Tkinter
- SQLite

# 📂 Project Files
- `main.py` → Main application file
- `screenshots/` → Project screenshots
- `Quiz_App_demo.mp4` → Demo video
